# Prison Break Stealth - Graphics & Visualization

## Project Overview
Prison Break Stealth is a joint project for Graphics & Visualization and Intelligent Systems.  
This repository contains the visual and interactive components of the game, including the prison environment, player interactions, custom 3D models, guard animation, and full scene integration.

## Core GV Features
- 3D prison environment
- Lighting and texturing
- Door and keycard interactions
- Custom 3D models
- Guard animation and path-following integration

## Team Members and Roles
- Student 1 - World Builder
- Student 2 - Systems Engineer
- Student 3 - Core Developer
- Student 4 - Agent Controller

## Folder Structure
- `docs/` - art direction, asset list, notes
- `game/` - Unity game project
- `demo/` - video plan and screenshots

## How to Run
1. Open the Unity project inside `game/`
2. Open `PrisonLevel`
3. Play the scene to test the prison escape flow
